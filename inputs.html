Pasos de tipo Inputs

Los inputs son pasos que capturan información del usuario. Cada tipo valida automáticamente el formato de la respuesta para garantizar datos limpios en tu flujo.

Lección en curso
Input · Texto

Texto

Captura cualquier respuesta escrita libre del usuario.

Se usa cuando se espera una respuesta de texto libre de parte del cliente. Es el input más versátil del flujo: acepta cualquier cadena de caracteres sin validación de formato. Ideal para capturar nombres, comentarios, descripciones o cualquier campo abierto donde el usuario deba escribir con sus propias palabras.

Cuándo usarlo

  • Capturar el nombre del usuario
  • Recoger comentarios o feedback
  • Pedir descripción de un problema
  • Cualquier campo de texto abierto

Comportamiento

  • Sin validación de formato
  • Acepta letras, números y símbolos
  • Guarda respuesta como variable
  • Continúa el flujo al recibir respuesta
Cómo añadirlo al flujo
1

Agrega el paso

Haz clic en + Agregar paso, ve a la sección Inputs y selecciona Texto.

2

Define el nombre de la variable

Asigna un nombre descriptivo a la variable donde se guardará la respuesta, por ejemplo nombre_cliente.

3

Usa la variable en el flujo

Reutiliza la respuesta en pasos siguientes con {{nombre_cliente}} para personalizar el mensaje.

Consejo: Coloca siempre un Paso de texto justo antes del input para hacerle la pregunta al usuario: "¿Cuál es tu nombre?". El input en sí no muestra ningún mensaje, solo espera la respuesta.

Input · Number

Number

Captura valores numéricos y valida automáticamente el formato.

Se usa cuando se espera una respuesta de tipo número de parte del cliente. El sistema valida automáticamente que la entrada sea un valor numérico válido antes de continuar el flujo. Si el usuario escribe texto u otro formato no numérico, el chatbot solicitará una corrección automáticamente.

Cuándo usarlo

  • Pedir una edad o año de nacimiento
  • Cantidad de personas o productos
  • Presupuesto o monto estimado
  • Número de pedido o referencia

Validación

  • Solo acepta dígitos numéricos
  • Admite decimales según configuración
  • Rechaza texto y caracteres especiales
  • Solicita corrección si el formato es inválido
Cómo añadirlo al flujo
1

Agrega el paso

En el editor, selecciona + Agregar paso → Inputs → Number.

2

Nombra la variable

Define un nombre claro como cantidad_personas o presupuesto para usar el valor más adelante.

3

Úsalo en condiciones

El valor numérico puede usarse en bloques de lógica condicional para bifurcar el flujo según el número ingresado.

Consejo: Indica claramente el rango esperado en el mensaje previo: "Ingresa un número entre 1 y 10". Esto reduce errores y mejora la experiencia del usuario.

Input · Email

Email

Captura y valida automáticamente direcciones de correo electrónico.

Se usa cuando se espera una respuesta de tipo correo electrónico. El sistema verifica automáticamente que el texto ingresado tenga el formato válido de un email (usuario@dominio.com). Si el formato es incorrecto, el chatbot pide al usuario que corrija su respuesta antes de continuar.

Cuándo usarlo

  • Registro de nuevos usuarios
  • Envío de cotizaciones o presupuestos
  • Suscripción a newsletter
  • Confirmaciones y notificaciones

Validación

  • Requiere formato @ y dominio
  • Verifica extensión válida (.com, .net…)
  • No verifica si el correo existe realmente
  • Solicita corrección si el formato es inválido
Cómo añadirlo al flujo
1

Agrega el paso

Selecciona + Agregar paso → Inputs → Email en el editor de flujo.

2

Asigna la variable

Nombra la variable como email_cliente para identificarla fácilmente y reutilizarla en pasos siguientes.

3

Conecta con integraciones

Usa la variable {{email_cliente}} para enviar correos automáticos, registrar en CRM o exportar datos.

Consejo: Incluye un ejemplo en el mensaje previo: "Ingresa tu correo electrónico (ej: usuario@gmail.com)". Reduce la tasa de errores de formato considerablemente.

Vista del usuario
¿A qué correo te enviamos la confirmación?

usuario@dominio.com
Input · Website

Website

Captura y valida URLs de sitios web con formato correcto.

Se usa cuando se espera una respuesta de tipo sitio web (URL). El sistema verifica que el texto ingresado tenga el formato de una URL válida, incluyendo el protocolo (https://) y el dominio. Si el formato no es correcto, el chatbot pedirá que se ingrese nuevamente.

Cuándo usarlo

  • Solicitar la web de una empresa
  • Pedir enlace a un portafolio o perfil
  • Recopilar redes sociales o landing pages
  • Referenciar un producto o recurso en línea

Validación

  • Requiere formato URL válido
  • Acepta http:// y https://
  • Verifica estructura del dominio
  • No verifica si el sitio está activo
Cómo añadirlo al flujo
1

Agrega el paso

Selecciona + Agregar paso → Inputs → Website.

2

Asigna la variable

Nombra la variable como web_empresa o url_portafolio para referenciarlo más adelante.

3

Usa la URL en el flujo

Puedes mostrar la URL capturada en un mensaje de confirmación usando {{web_empresa}}.

Consejo: Indica el formato esperado en el mensaje previo: "Ingresa la URL completa de tu sitio web (ej: https://tuempresa.com)".

Vista del usuario

Input · Phone

Phone

Captura números de teléfono con código de país incluido.

Se usa cuando se espera una respuesta de tipo número de teléfono. Este input valida que la respuesta incluya obligatoriamente el código de país (por ejemplo +51 para Perú, +34 para España, +1 para Estados Unidos) seguido del número local. Es el estándar internacional para asegurar que el número sea contactable desde cualquier lugar.

Cuándo usarlo

  • Capturar número para llamadas o SMS
  • Contacto de seguimiento comercial
  • Registro de usuarios con WhatsApp
  • Verificación de identidad por teléfono

Formato requerido

  • Debe incluir + y código de país
  • Ej: +51 987 654 321
  • Ej: +34 612 345 678
  • Rechaza números sin código de país
Cómo añadirlo al flujo
1

Agrega el paso

Selecciona + Agregar paso → Inputs → Phone.

2

Define la variable

Nombra la variable como telefono_cliente para usarlo en integraciones de WhatsApp, CRM o notificaciones.

3

Indica el formato en el mensaje

En el paso de texto previo, especifica que debe incluir el código de país: "Incluye el código de tu país (ej: +51)".

Importante: El código de país es obligatorio. Si el usuario escribe solo el número local sin el prefijo +, el sistema lo rechazará y pedirá que ingrese el formato correcto.

Vista del usuario
¿Cuál es tu número de WhatsApp? Incluye el código de tu país (ej: +51 987 654 321)

+51 987 654 321
Input · Buttons

Buttons

Presenta opciones de respuesta rápida como botones clickeables.

Se usa para brindar opciones de respuesta rápida al usuario mediante botones. En lugar de que el usuario escriba libremente, selecciona una de las opciones predefinidas con un solo clic. Ideal para guiar el flujo de conversación con respuestas controladas y evitar entradas inesperadas.
Máximo  9 opciones
Máximo  20 caracteres por botón

Cuándo usarlo

  • Preguntas de sí / no
  • Selección de categoría o servicio
  • Menú de opciones del chatbot
  • Elección de horario o turno
  • Confirmación de datos antes de enviar

Límites y reglas

  • Mínimo 2, máximo 9 botones
  • Cada botón: máx. 20 caracteres
  • Solo una opción seleccionable
  • El valor del botón se guarda en variable
  • Permite bifurcar el flujo por opción
Cómo añadirlo al flujo
1

Agrega el paso

Selecciona + Agregar paso → Inputs → Buttons.

2

Define las opciones

Escribe cada opción de botón. Recuerda: máximo 9 botones y 20 caracteres por texto. Sé breve y claro: "Sí, confirmar", "No, cancelar".

3

Conecta cada botón

Desde la salida de cada botón arrastra un conector hacia el siguiente paso correspondiente para bifurcar el flujo según la elección.

Consejo: Usa textos cortos y directos en los botones. Evita palabras ambiguas. Máximo 3–4 palabras por botón es lo ideal para que el usuario tome la decisión rápido.

Input · Text w/ Wait

Text w/ Wait

Captura texto libre y aplica un tiempo de espera configurable.

Se usa cuando se espera una respuesta de tipo texto y a la vez se necesita aplicar un tiempo de espera antes de continuar el flujo. A diferencia del paso de texto normal, este input aguarda un período configurable luego de recibir la respuesta —o en ausencia de ella— antes de avanzar. Útil para dar tiempo al usuario a completar su respuesta o para gestionar respuestas que pueden llegar en varios mensajes.

Cuándo usarlo

  • Respuestas largas enviadas en partes
  • Dar tiempo al usuario antes de continuar
  • Esperar confirmación con pausa natural
  • Formularios donde el usuario puede tardar

Comportamiento

  • Acepta texto libre sin validación
  • Aplica un temporizador configurable
  • Continúa al vencer el tiempo de espera
  • Guarda la última respuesta como variable
Cómo añadirlo al flujo
1

Agrega el paso

Selecciona + Agregar paso → Inputs → Text w/ Wait.

2

Configura el tiempo de espera

Define en segundos cuánto tiempo esperará el sistema antes de continuar. Ajusta según el tipo de respuesta esperada.

3

Define qué ocurre después

Conecta la salida del paso al siguiente bloque del flujo que se ejecutará una vez vencido el tiempo de espera.

Importante: No abuses de tiempos de espera muy largos. Un tiempo excesivo puede frustrar al usuario si siente que el chatbot no responde. Usa tiempos cortos (5–15 segundos) salvo que el caso lo justifique.

Input · Rating

Rating

Captura calificaciones de encuestas mediante estrellas u opciones numéricas.

Se usa cuando se espera una respuesta de tipo calificación para una encuesta o evaluación. El usuario responde eligiendo una puntuación dentro de una escala predefinida (normalmente de 1 a 5 estrellas). La calificación se guarda como valor numérico en una variable para su posterior análisis o uso en el flujo.

Cuándo usarlo

  • Encuestas de satisfacción del cliente
  • Calificación de productos o servicios
  • Evaluación de atención al cliente
  • NPS (Net Promoter Score)
  • Valoración de una experiencia

Comportamiento

  • Escala visual de estrellas (1–5)
  • Guarda el valor numérico de la calificación
  • Permite bifurcar el flujo por puntuación
  • Un solo clic para seleccionar y continuar
Cómo añadirlo al flujo
1

Agrega el paso

Selecciona + Agregar paso → Inputs → Rating.

2

Define la pregunta previa

Añade un paso de texto antes con la pregunta de la encuesta: "¿Cómo calificarías nuestra atención del 1 al 5?"

3

Usa la calificación en el flujo

Con la variable guardada puedes enviar respuestas diferenciadas: un agradecimiento especial para calificaciones altas, o un mensaje de disculpa y mejora para las bajas.

Consejo: Combina el paso de Rating con una bifurcación condicional para enviar mensajes personalizados según la puntuación. Por ejemplo, si calificación es menor a 3, activa un flujo de atención al cliente proactivo.
